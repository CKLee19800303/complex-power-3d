分支 n
指定 x 的截面彩色點是所選分支在此 x 的值；淡色圓只是模長參考，並不表示整個圓都是解。
負半軸：
kₙ = exp[(ln|x| + i(2n+1)π)/x]

正半軸（多值模式）：
kₙ = exp[(ln x + i2nπ)/x]

n = 0 使用主值選擇，負半軸取 arg(x) = π。不同 n 在某些 x 會重合。圖中僅顯示 n = −3…3，不包含所有整數分支。

x → 0⁻ 時模長急遽增大；負半軸終點限制為 ≤ −0.1。三軸分別縮放以便觀察，刻度顯示原始數值。
